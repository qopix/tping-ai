# TPING-AI 🤖🛰️

**TPING-AI** — это автономный ИИ-агент (AI Agent) на языке Go с открытым исходным кодом и полным отсутствием встроенной цензуры. Программа работает по циклу **Thought -> Action -> Observation** (Мысль -> Действие -> Наблюдение). 

Главная особенность агента — **способность обучаться на лету**. Вы можете передать ему ссылку на любой репозиторий GitHub (например, ваш собственный сетевой инструмент), ИИ автоматически склонирует его, изучит исходный код, поймет доступные флаги и логику работы, сам скомпилирует проект и выполнит сетевой тест по вашему текстовому запросу.

---

## 🔥 Возможности

- **Полная автономность:** Самостоятельно планирует шаги для решения поставленной инженерной или исследовательской задачи.
- **Обучение «из коробки»:** Скачивает сторонний код, парсит файлы (`.cpp`, `.go`, `.md`, `Makefile`) и понимает логику работы утилит без предварительной настройки.
- **Управление ОС Linux:** Самостоятельно компилирует проекты и выполняет бинарники с нужными флагами через системные вызовы.
- **100% Локально и Бесплатно:** Работает на базе локального движка Ollama. Ваши запросы, код и данные не отправляются на сторонние корпоративные сервера.
- **Без цензуры (Uncensored):** Благодаря использованию моделей семейства Dolphin, ИИ не имеет этических фильтров и без отказов пишет скрипты автоматизации, эксплоиты и генерирует стресс-тесты.

## 🏗️ Архитектура проекта

Кодовая база разделена на модули для удобства кастомизации и расширения:
- `main.go` — Главный управляющий цикл агента (точка входа).
- `config.go` — Настройки подключения к Ollama и базовые системные промпты (инструкции для ИИ).
- `agent.go` — Мозг агента: отвечает за генерацию мыслей ИИ, потоковый вывод текста и парсинг вызовов инструментов.
- `tools.go` — Системные инструменты: интеграция с Git, чтение файлов с диска, компиляция (GCC/Go) и выполнение бинарников.
- `models.go` — Структуры данных для JSON-взаимодействия с API.
- `Makefile` — Скрипт для быстрой автоматической сборки проекта.

## 🛠️ Требования для работы

Для работы утилиты на вашем компьютере должны быть установлены:
1. **Язык Go** (версии 1.20 или выше)
2. **Утилита Git**
3. **Компиляторы** (например, `build-essential` / `make` / `g++` для сборки изучаемых проектов)
4. **Ollama** (локальный сервер ИИ)

### Подготовка модели (Ollama)
Перед запуском агента установите и запустите бесцензурную модель в терминале:
```bash
# Скачивание и запуск модели без цензуры
ollama run dolphin-mistral
```
*После загрузки интерфейс модели можно закрыть (Ctrl+D), сервер продолжит работать в фоне на порту 11434.*

## 🚀 Установка и Запуск

Склонируйте репозиторий с ИИ-агентом и воспользуйтесь встроенным `Makefile`:

```bash
# Сборка проекта
make

# Запуск ИИ-агента одной командой (автоматически соберет и запустит)
make run

# Очистка рабочего пространства от скачанных ИИ репозиториев
make clean
```

## 💡 Примеры использования

После запуска программы введите вашу задачу обычным человеческим языком прямо в консоль `User > `:

### Пример 1: Исследование и тест с обучением на ходу
```text
User > Изучи мой проект https://github.com и протестируй устойчивость сайта httpbin.org в режиме slowloris на 10 секунд
```
**Что сделает ИИ-агент автоматически:**
1. Вызовет инструмент `TOOL_CLONE` и скачает репозиторий во временный воркспейс.
2. Вызовет `TOOL_READ_FILES`, прочитает исходный код ваших файлов `.cpp` и `Makefile`.
3. Поймет, что режим `slowloris` находится в `tping3.cpp` и требует флаги `-url` и `-mode`.
4. Вызовет `TOOL_COMPILE:make tping3` для реальной сборки вашего кода.
5. Запустит тест командой `TOOL_RUN:./tping3 -url http://httpbin.org -mode slowloris -t 100 -d 10`.
6. Проанализирует вывод вашего бинарника и выдаст вам итоговый отчет.

### Пример 2: Написание технического кода
```text
User > Напиши bash-скрипт для автоматического парсинга открытых портов и выведи его на экран
```
