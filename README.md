# TPING-AI (Full-System Autonomous AI Agent) 🤖📂🛰️

**TPING-AI** — это продвинутый автономный ИИ-агент на языке Go, работающий по принципу **Thought -> Action -> Observation** (Мысль -> Действие -> Наблюдение). Утилита не имеет встроенной цензуры и обладает полным доступом к файловой системе Linux.

Главная особенность агента — **способность к автономному обучению и управлению кодом**. Вы можете передать ему ссылку на любой Git-репозиторий. ИИ сам скачает его, изучит структуру папок, прочитает исходный код (C++, Go, Bash), сможет сам переписать или дописать функции, удалить старые логи, создать новые скрипты автоматизации и скомпилировать финальный софт под нужную вам платформу (включая Android-скрипты).

---

## 🔥 Расширенные возможности

- **Полный доступ к ФС (File-System Agent):** ИИ умеет просматривать директории, читать, создавать, перезаписывать и удалять любые файлы в рабочем пространстве.
- **Обучение и модификация на лету:** Бот анализирует исходный код инструментов, понимает их логику и может по вашему запросу модернизировать алгоритмы (например, добавить новый метод сетевого теста в `.cpp` файл).
- **Прямое управление компиляцией:** Самостоятельно вызывает системные сборщики (`make`, `go build`, `gcc`), анализирует ошибки компилятора и исправляет код в случае сбоев.
- **Гибридная архитектура (ПК + Облако):** Вы можете запускать управляющую панель на своем Linux-ПК (Kali), а тяжелую нейросеть вынести на бесплатные сервера **GitHub Codespaces** через встроенный проброс портов.
- **100% Без цензуры (Uncensored):** Модели не имеют этических ограничений, создают любые проверочные скрипты, эксплоиты и нагрузочные инструменты по первому требованию.

## 🏗️ Архитектура и структура файлов

Проект разделен на логические модули:
- `main.go` — Главный цикл размышлений агента и обработчик результатов выполнения команд.
- `config.go` — Системный промпт (инструкции ИИ) и адрес подключения к бэкенду.
- `agent.go` — Модуль отправки контекста в Ollama, стриминга ответов и парсинга триггеров.
- `tools.go` — Физическая реализация инструментов (Git, чтение/запись/удаление файлов, сборка, `exec` команд).
- `models.go` — JSON-структуры для работы с API.
- `Makefile` — Скрипт для быстрой автоматической компиляции агента.

## 🛠️ Системный интерфейс инструментов (Action Tools)

ИИ принимает решения автономно, вызывая на новой строке следующие системные триггеры:
1. `TOOL_CLONE:<url>` — Клонирование удаленного Git-репозитория.
2. `TOOL_LIST_DIR:<path>` — Просмотр списка файлов и папок.
3. `TOOL_READ_FILE:<path>` — Чтение содержимого конкретного файла.
4. `TOOL_WRITE_FILE:<path>|<content>` — Создание или полная перезапись файла.
5. `TOOL_DELETE_FILE:<path>` — Удаление файла или директории.
6. `TOOL_COMPILE:<command>` — Запуск компиляции (`make`, `go build` и т.д.).
7. `TOOL_RUN:<command>` — Выполнение любого бинарника или скрипта в ОС Linux.

## 🚀 Установка и Сборка на вашем ПК (Kali Linux)

Перейдите в папку с проектом и выполните сборку через встроенный `Makefile`:

```bash
# Инициализация модуля (если запускается впервые)
go mod init tping-ai

# Автоматическая компиляция ИИ-агента
make build

# Запуск агента
./tping-ai
```

## 🔗 Интеграция с GitHub Codespaces (Бесплатный бэкенд для ИИ)

Если ваш ПК или ноутбук слишком слабый, вы можете запустить сервер ИИ на мощностях GitHub абсолютно бесплатно:
1. Зайдите на **[://github.com](https://://github.com)** и создайте пустой Codespace (**Blank**).
2. В терминале Codespaces вставьте команду для чистой установки Ollama:
   ```bash
   sudo curl -L https://github.com -o /usr/bin/ollama && sudo chmod +x /usr/bin/ollama
   ```
3. Запустите ИИ-сервер в фоне и скачайте быструю оптимизированную модель:
   ```bash
   ollama serve > /dev/null 2>&1 &
   ollama pull qwen2.5:1.5b
   ```
4. Откройте вкладку **Ports** внизу экрана Codespaces, нажмите **Add Port**, введите `11434`.
5. Нажмите правой кнопкой мыши по добавленному порту ➔ **Port Visibility** ➔ переключите на **Public**.
6. Скопируйте адрес из колонки *Forwarded Address* и вставьте его в файл `config.go` на вашей Kali Linux в константу `ollamaURL` (не забудьте добавить в конец `/api/chat`).

## 💡 Примеры комплексных задач для ИИ

После запуска `./tping-ai` на вашей Kali Linux вы можете ставить агенту сложные многоуровневые задачи:

- **Пример 1 (Модификация кода):** 
  `User > Изучи репозиторий https://github.com, открой файл tping3.cpp, перепиши в нем логику User-Agent, добавив туда ротацию из 10 новых браузеров, удали файл old_notes.txt и скомпилируй проект заново.`
  
- **Пример 2 (Автоматизация под мобильные платформы):**
  `User > Склонируй мой проект с гитхаба, изучи его и напиши bash-скрипт build_android.sh, который позволит подготовить и собрать этот сетевой инструмент для работы внутри Android-окружения Termux.`

## ⚠ Предупреждение о безопасности (Disclaimer)

Данный ИИ-агент обладает правами на выполнение произвольного кода, компиляцию программ, создание, изменение и безвозвратное удаление файлов в рамках директории `./agent_workspace`. 
- Перед запуском сложных команд убедитесь, что вы предоставили агенту корректные инструкции.
- Используйте инструмент исключительно в рамках легитимных тестов на проникновение, аудита безопасности собственной инфраструктуры или в образовательных целях.
